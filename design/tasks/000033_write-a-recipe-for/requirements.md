# Requirements: Tomato Soup Recipe

## User Stories

- As a home cook, I want a clear tomato soup recipe so I can make it from scratch.
- As a reader, I want ingredient quantities and step-by-step instructions so I can follow along easily.

## Acceptance Criteria

- [ ] Recipe includes a full ingredient list with quantities
- [ ] Step-by-step cooking instructions are provided
- [ ] Prep time and cook time are listed
- [ ] Serving size is specified
- [ ] Instructions are clear enough for a beginner cook

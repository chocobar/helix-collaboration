# Requirements: Chicken Soup Recipe

## User Stories

- As a user, I want a chicken soup recipe in markdown format so I can read and follow it easily.

## Acceptance Criteria

- [ ] Recipe is written in well-formatted Markdown
- [ ] Includes a title, ingredient list, and step-by-step instructions
- [ ] Ingredients include quantities
- [ ] Steps are numbered and clear
- [ ] Includes prep time and cook time
- [ ] Serves as a standalone `.md` file

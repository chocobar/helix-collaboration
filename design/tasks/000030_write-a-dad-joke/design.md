# Design: Write a Dad Joke

## Approach

Deliver a single, original dad joke using the classic setup-and-punchline format with a pun.

## The Joke

**Q:** Why do programmers prefer dark mode?

**A:** Because light attracts bugs.

## Decision Rationale

- Chose a programming-themed joke since we're in a software context
- Uses the classic question-and-answer dad joke structure
- The pun works on two levels: literal bugs (insects) and software bugs

# Requirements: Blog Post About Sorting Algorithms

## User Stories

- As a reader, I want a clear explanation of common sorting algorithms so I can understand how they work and when to use each one.
- As a reader, I want visual/textual examples showing each algorithm's step-by-step process so I can follow the logic.
- As a reader, I want a comparison of time and space complexity so I can choose the right algorithm for my use case.

## Acceptance Criteria

- [ ] Post is written in valid Markdown
- [ ] Covers at least 5 sorting algorithms (e.g., Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort)
- [ ] Each algorithm includes: a brief description, how it works (step-by-step), time complexity (best/average/worst), and space complexity
- [ ] Includes a summary comparison table of all algorithms
- [ ] Code examples are provided in a common language (e.g., Python) using fenced code blocks
- [ ] Post has a logical structure: introduction, individual algorithm sections, comparison, and conclusion
- [ ] Content is accurate and beginner-friendly
- [ ] Post is between 1500-3000 words

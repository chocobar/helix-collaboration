## Snake (terminal game)

Play snake in your terminal with `snake.py` (Python 3 stdlib only, no dependencies).

```sh
python3 snake.py               # play yourself
python3 snake.py --auto        # watch an AI play
```

Controls: arrow keys or WASD to steer, `Q` to quit, `R` to restart after game over.

Options: `--width`, `--height` (board size), `--speed` (ticks per second, 1-60),
`--seed` (deterministic food placement).
